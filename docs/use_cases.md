# Use Case Document (UCD)

## UC01: Business Analyst Agent
Interrogates requirements, captures feedback via BA-customer communication, updates BRD/UCD/TCD/UI/UX/tech stack automatically. No endless loops; BA ensures clarification before proceeding.

## UC02: Developer Agent
Generates Flutter + Spring Boot scaffolds using BLoC architecture.

## UC03: Tester Agent
Validates compliance and traceability against auto-generated test cases.

## UC04: Compliance Agent
Enforces DPDP/GDPR, generates privacy policies and compliance checklists.

## UC05: UI/UX Expert Agent
Designs flows, generates wireframes/mockups, ensures accessibility and localization.

## UC06: Solutions Architect Agent
Suggests integrations and architecture, prioritizing India-first solutions.

## UC07: CLI Extension
Triggers agents directly from VS Code (`ucto init`, `ucto sprint`, `ucto agent`, `ucto deploy`).
