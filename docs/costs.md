# Cost Breakdown

## Infrastructure
- VPS (Hetzner/OVH/DigitalOcean): $60–$100/mo.
- GPU/API inference (AWS/GCP/Azure): $300–$600/mo.
- Object Storage (Backblaze/Wasabi/S3): $10–$30/mo.
- CDN + Load Balancer (Cloudflare/NGINX/Traefik): $20–$50/mo.

## AI & Generative Services
- LLM API (OpenAI/Azure/Anthropic): $100–$300/mo.
- Generative Design AI (Figma plugin/API): $50–$150/mo.
- LangChain/Semantic Kernel: Free.

## Backend & Business Services
- Chargebee MCP: ~$100/mo.
- PostgreSQL + Redis: $20–$50/mo.
- SMTP/Email (Zoho): $10–$20/mo.
- SMS Gateway (Zoho/MSG91/TextLocal): ₹0.15–₹0.25 per SMS.

## Frontend & Design
- Flutter Build Tools: Free.
- Design System Repository: Included.
- Localization Hooks: Included.

## Monitoring & Analytics
- Prometheus + Grafana: Included.
- Mixpanel/Amplitude: $50–$150/mo.

## India-First Integrations
- Payment Gateway (Razorpay/PayU): 2–3% per transaction.
- CRM (Zoho/Freshworks): $50–$200/mo.
- DigiLocker Plugin: Free.

## Monthly Estimate
- MVP (10 customers): $500–$800 (~₹42k–₹67k).
- Scaling (100+ customers): $1,200–$2,000 (~₹100k–₹167k).
- Enterprise (500+ customers): $3,000–$5,000 (~₹250k–₹420k).
