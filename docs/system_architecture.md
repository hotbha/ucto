# System Architecture

## Core Services
- Spring Boot: Auth, requirements, audit logs, compliance APIs
- Chargebee: Subscriptions, payments, analytics

## AI Agents
- Business Analyst, Developer, Tester, Compliance, UI/UX Expert, Solutions Architect

## Databases
- PostgreSQL (primary)
- Redis (cache)
- Object Storage (screens, docs)

## Integrations
- Zoho SMTP/SMS
- Razorpay
- DigiLocker (optional KYC)

## Deployment Layers
- Docker Compose (MVP)
- Kubernetes (scaling)

## Enhancements
- Design System Repository
- Localization Hooks
- Load Balancer (NGINX/Traefik)
- Analytics (Mixpanel/Amplitude)
